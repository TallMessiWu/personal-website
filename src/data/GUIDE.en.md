# Cloud Database Data Entry Guide

This document explains the data structure specifications for the `posts` collection (used for daily updates) and the `collections` collection (used for the portfolio showcase) in the Tencent CloudBase database. **Please enter data according to this specification within the CloudBase console or the admin dashboard.**

## 1. `posts` Collection (Daily Updates)

Each document in the collection contains the following fields:

### Core Properties

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `_id` | `string` | Yes | Unique identifier. Automatically generated by cloud database, no manual entry required. |
| `title` | `string` | Yes | Post title. |
| `content` | `string` | No | Post body text, supports `\n` for new lines. |
| `date` | `string` | Yes | Release date, format: `YYYY-MM-DD HH:mm`. |
| `pinned` | `boolean` | No | If true, the post will be shown at the top of the list. |

### Media Properties

#### `images` (Array)
The `images` field is an array of `ImageItem` objects:

- `image`: **Original Image (High-Res)**. Used in the fullscreen viewer. Can be a CloudBase storage `cloud://` URL or a public HTTP URL.
- `thumbnail`: **Thumbnail (Low-Res)**. Used for the masonry grid and modal preview. *Highly recommended for faster loading.*
- `video`: **Live Photo Video URL**. If provided, the image will act as a Live Photo and auto-play in the details view.

#### `video` (External Video)
- `video`: Used for external video links like Bilibili. Currently supports auto-detection and embedding of Bilibili BVIDs.

---

### `posts` Example Configurations

#### 1. Title Only
```typescript
{
  title: 'Mood today: Sunny',
  date: '2024-02-19 09:00'
}
```

#### 2. Text Only
```typescript
{
  title: 'Reading Notes',
  content: 'Read "Hackers & Painters" today. Great insights.\nInnovation is timeless.',
  date: '2024-02-19 10:30'
}
```

#### 3. Single Image
```typescript
{
  title: 'Afternoon Coffee',
  images: [
    {
      image: 'cloud://your-env-id.ext/assets/daily/coffee-hd.jpg',
      thumbnail: 'cloud://your-env-id.ext/assets/daily/coffee-thumb.jpg'
    }
  ],
  date: '2024-02-19 14:00'
}
```

#### 4. Multiple Images with Live Photo
```typescript
{
  title: 'Sunset by Erhai Lake',
  images: [
    {
      image: 'cloud://your-env-id.ext/assets/daily/sunset-static.jpg',
      thumbnail: 'cloud://your-env-id.ext/assets/daily/sunset-static-t.jpg'
    },
    {
      image: 'cloud://your-env-id.ext/assets/daily/sunset-live.jpg',
      thumbnail: 'cloud://your-env-id.ext/assets/daily/sunset-live-t.jpg',
      video: 'cloud://your-env-id.ext/assets/daily/sunset-live.mov' // Live Photo Video
    }
  ],
  date: '2024-02-19 18:20'
}
```

#### 5. Bilibili Video
```typescript
{
  title: 'Awesome Video Recommendation',
  content: 'This video is very well explained.',
  video: 'https://www.bilibili.com/video/BV1v63xz3EwX/',
  images: [{ image: 'cloud://your-env-id.ext/assets/daily/video-cover.jpg' }], // Recommended to provide a cover image manually
  date: '2024-02-19 20:00'
}
```

## 2. `collections` Collection (Portfolio)

Each document in the collection contains the following fields:

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `_id` | `string` | Yes | Unique identifier. Automatically generated by cloud database, no manual entry required. |
| `name` | `string` | Yes | Collection name. |
| `thumbnail` | `string` | No | Cover image link (Cloud Storage ID or external URL). If left empty, the system will automatically fall back to the first image from its contained posts. |
| `posts` | `string[]` | Yes | An array of `_id` references to documents in the `posts` collection. |
| `latestPostDate` | `string` | Yes | Date of the latest update, format: `YYYY-MM-DD HH:mm`. |
| `pinned` | `boolean` | No | If true, the collection will be shown at the top. |

### `collections` Example Configuration

```typescript
{
  name: 'Western Sichuan Trip 2024',
  thumbnail: '', // Leave empty to automatically fallback to the referenced post images
  posts: [
    'fcc24a0d66c1b35b0028e37e57c61cd6',
    '342cb25d66c1b38f00223df40ccbb186'
  ],
  latestPostDate: '2024-05-12 10:00',
  pinned: true
}
```
